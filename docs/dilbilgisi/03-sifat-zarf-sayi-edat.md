# 3. Sıfat, Zarf, Sayı, Edat, Bağlaç

## 3.1 Sıfat (rengdêr)
Sıfat ismin **arkasına** gelir ve isme izafet ekiyle bağlanır (bkz. [2.5](02-isim-izafet-zamir.md#25-izafet-îzafe-tamlama-ve-sıfat-bağlama)):

| Kurmancî | Türkçe |
|---|---|
| *bajarê mezin* | büyük şehir |
| *keça biçûk* | küçük kız |
| *hevalên baş* | iyi arkadaşlar |
| *xaniyekî nû* | yeni bir ev |

Yüklem olarak kullanılan sıfat ek-fiil alır: *Bajar mezin e.* = Şehir büyüktür.

### Karşılaştırma
| Derece | Ek | Örnek |
|---|---|---|
| Karşılaştırma | **-tir** | *mezintir* (daha büyük) |
| Üstünlük | **-tirîn** | *mezintirîn* (en büyük) |

- *Wan **ji** Mêrdînê mezintir e.* = Van, Mardin'den daha büyüktür. (karşılaştırılan *ji* ile)
- *Ew **baştirîn** heval e.* = O en iyi arkadaştır. (*-tirîn* alan sıfat ismin **önüne** geçer)
- Düzensiz: *baş* (iyi) → *çêtir* (daha iyi) de kullanılır.

## 3.2 Zarf (hoker)
Zarfların bir kısmı kök hâlindedir: *zû* (erken, çabuk), *dereng* (geç), *niha* (şimdi), *îro* (bugün), *sibê* (yarın), *duh* (dün), *li vir* (burada), *li wir* (orada), *pir* / *gelek* (çok), *hêdî* (yavaş).
Sıfattan zarf türetmek için **-ane** eki kullanılır (Türkçe "-ca/-ce"): *mêr* → *mêrane* (yiğitçe), *dost* → *dostane* (dostça).
Sıfatlar çoğu zaman olduğu gibi zarf olarak da kullanılır: *Baş dixebite.* = İyi çalışıyor.

## 3.3 Sayılar (hejmar)
| | | | | | |
|---|---|---|---|---|---|
| 1 *yek* | 2 *du* | 3 *sê* | 4 *çar* | 5 *pênc* | 6 *şeş* |
| 7 *heft* | 8 *heşt* | 9 *neh* | 10 *deh* | 11 *yazdeh* | 12 *diwanzdeh* |
| 13 *sêzdeh* | 14 *çardeh* | 15 *panzdeh* | 16 *şanzdeh* | 17 *hivdeh* | 18 *hejdeh* |
| 19 *nozdeh* | 20 *bîst* | 30 *sî* | 40 *çil* | 50 *pêncî* | 60 *şêst* |
| 70 *heftê* | 80 *heştê* | 90 *nod* | 100 *sed* | 1000 *hezar* | 1.000.000 *milyon* |

- **Bileşik sayılar** *û* (ve) ile bağlanır: 21 = *bîst û yek*, 345 = *sê sed û çil û pênc*.
- **Sıra sayıları** *-em* (ya da *-emîn*) ekiyle yapılır: *yekem* (birinci), *duyem* (ikinci), *sêyem* (üçüncü), *çarem* (dördüncü). *-emîn* alan sıra sayısı ismin önüne geçer: *yekemîn car* (ilk kez).
- **Sayıdan sonra isim tekil kalır** (Türkçedeki gibi): *sê pisîk* (üç kedi).
- **Ağız notu:** 12 için *dwanzdeh* ve *dozdeh*, 15 için *pazdeh* gibi biçimler de yaygındır.

## 3.4 Edatlar (daçek)
Edattan sonra isim ve zamir **bükümlü** hâlde olur (*li malê*, *ji min*).

### Ön edatlar (pêşdaçek)
| Edat | Anlam | Örnek |
|---|---|---|
| *li* | -de, -e (yer, yön) | *li Wanê* (Van'da) |
| *ji* | -den; -in (bir parçası) | *ji Amedê* (Diyarbakır'dan) |
| *bi* | ile (araç), -le | *bi trênê* (trenle) |
| *di* | içinde (genelde *de* ile) | *di malê de* (evin içinde) |
| *bo* / *ji bo* | için | *ji bo te* (senin için) |
| *bê* | -sız | *bê av* (susuz) |
| *ber* | önü, yanı | *ber derî* (kapının önü) |
| *heta* / *heya* | -e kadar | *heta sibê* (yarına kadar) |

### Çevre edatlar (bazinedaçek)
İsim iki parçanın **arasına** girer:

| Yapı | Anlam | Örnek |
|---|---|---|
| *di ... de* | içinde | *di odeyê de* (odada) |
| *ji ... re* | -e, için (alıcı) | *ji min re* (bana) |
| *bi ... re* | ile birlikte | *bi te re* (seninle) |
| *ji ... ve* | -den beri | *ji sibê ve* (sabahtan beri) |
| *li ... ser* | üstünde | *li ser maseyê* (masanın üstünde) |
| *di ... re* | içinden, üzerinden | *di pirê re* (köprünün üzerinden) |

### Edat birleşmeleri
Edat ile 3. kişi zamiri birleşebilir: *bi* + *wî* → *pê*, *ji* + *wî* → *jê*, *li* + *wî* → *lê*. Örnek: *Ez jê hez dikim.* = Onu seviyorum.

## 3.5 Bağlaçlar (girêdek)
| Kurmancî | Türkçe |
|---|---|
| *û* | ve |
| *an* / *yan* | veya |
| *lê* / *lêbelê* | ama |
| *jî* | de, da (kendinden önceki kelimeye bağlanır): *Ez jî têm.* (Ben de geliyorum.) |
| *ji ber ku* | çünkü |
| *ku* | ki, -dığı (bkz. [6. bölüm](06-cumle-ve-soru.md)) |
| *heke*, *eger*, *ger* | eğer |
| *hem ... hem* | hem ... hem |
| *ne ... ne* | ne ... ne |
| *dema ku* | -dığı zaman |
| *berî ku* / *piştî ku* | -madan önce / -dıktan sonra |

## 3.6 Ünlemler (baneşan)
*Erê* (evet), *na* (hayır), *belê* (evet, efendim), *wey* (vay), *ax* (ah), *de* (haydi), *aferîn* (aferin), *spas* (teşekkürler), *silav* (selam).

```

```
Çevre edat *ji … re* (§3.4).
