# 5. Kelime Yapımı (Peyvsazî)

Kurmancî kelime türetmek için **ön ekler**, **son ekler**, **ön fiiller** ve **birleştirme** kullanır. Bir kelimenin gerçekten Kürtçe içinde türetilip türetilmediğini anlamak için bu kurallar önemlidir. Etimoloji sınıflandırmasındaki `internal` (iç türetme) sınıfı bu yapılara dayanır. Ayrıntı için bkz. [etimoloji](../etimoloji.md).

## 5.1 Sık kullanılan yapım ekleri
| Ek | İşlev | Örnek |
|---|---|---|
| **-î** | isimden soyut isim ya da sıfat | *heval* → *hevalî* (arkadaşlık), *Kurd* → *kurdî* (Kürtçe) |
| **-tî** / **-ayî** | soyut isim (-lık) | *bira* → *biratî* (kardeşlik), *xweş* → *xweşî* (hoşluk) |
| **-kar** / **-ker** | yapan, meslek | *xebat* → *xebatkar* (çalışkan), *karker* (işçi) |
| **-van** | koruyan, işiyle uğraşan | *baxçe* → *baxçevan* (bahçıvan), *ga* → *gavan* (sığırtmaç) |
| **-dar** | sahip olan (-lı) | *birîn* → *birîndar* (yaralı), *xwîn* → *xwîndar* |
| **-ok** / **-ik** | küçültme, sevgi | *dar* → *darik* (çubuk), *gund* → *gundik* |
| **-istan** / **-stan** | yer adı (-lık) | *Kurd* → *Kurdistan*, *dibistan* (okul) |
| **-geh** / **-gah** | yer | *rawestgeh* (durak) |
| **-xane** | bina, yer | *nexweşxane* (hastane), *çapxane* (matbaa) |
| **-bar** | dolu, taşıyan | *xem* → *xembar* (gamlı) |
| **-ane** | zarf (-ca) | *dostane* (dostça) |
| **-andin** | ettirgen fiil (bkz. 5.5) | *kenîn* → *kenandin* (güldürmek) |
| **bê-** | -sız | *bêkar* (işsiz), *bêhêvî* (umutsuz) |
| **ne-** | olumsuz sıfat | *nexweş* (hasta, "hoş olmayan"), *nebaş* (kötü) |
| **hev-** | ortaklık (birlikte) | *hevkar* (iş arkadaşı), *hevwelatî* (vatandaş) |

> Bütün yapım eklerinin listesi ve örnekleri depoda yer alır: [`data/kmr/db/affixes.tsv`](../../data/kmr/db/affixes.tsv) (561 ek). Bu dosya hangi kelimelerde hangi ekin geçtiğini de gösterir.

## 5.2 Ön fiiller (pêşlêker)
Fiilin önüne gelerek anlamı değiştirirler. Bitişik yazılırlar. Şimdiki zaman eki *di-* ön fiil ile kök arasına girer.

| Ön fiil | Anlam yönü | Örnek | Şimdiki zaman |
|---|---|---|---|
| **ve-** | açma, geri | *vekirin* (açmak), *vegerîn* (dönmek) | *vedikim*, *vedigerim* |
| **ra-** | yukarı, kalkma | *rabûn* (kalkmak), *razan* (uyumak) | *radibim*, *radizêm* |
| **da-** | aşağı | *daketin* (inmek), *danîn* (koymak) | *dadikevim*, *datînim* |
| **hil-** | yukarı kaldırma | *hilgirtin* (kaldırmak) | *hildigirim* |
| **der-** | dışarı | *derketin* (çıkmak) | *derdikevim* |
| **wer-** | çevirme | *wergerandin* (çevirmek) | *werdigerînim* |
| **rû-** | oturma | *rûniştin* (oturmak) | *rûdinim* |

## 5.3 Birleşik fiiller (lêkerên hevedudanî)
Kurmancî'de fiillerin büyük bölümü **isim + yardımcı fiil** biçimindedir. Türkçedeki "etmek, olmak" yapılarına benzer. Yardımcı fiil çekimlenir, isim ayrı yazılır.

| Yardımcı fiil | Örnek | Türkçe |
|---|---|---|
| *kirin* (yapmak) | *kar kirin*, *hez kirin*, *alîkarî kirin*, *telefon kirin* | çalışmak, sevmek, yardım etmek, telefon etmek |
| *bûn* (olmak) | *aciz bûn*, *nexweş bûn* | bıkmak, hastalanmak |
| *dan* (vermek) | *bersiv dan*, *xwe dan* | cevap vermek |
| *girtin* (tutmak) | *wêne girtin* | fotoğraf çekmek |
| *xistin* (düşürmek) | *dest xistin* | ele geçirmek |
| *ketin* (düşmek) | *dest ketin* | ele geçmek |

*hez kirin* ve *ji ... hez kirin*: sevilen şey *ji* ile gelir: *Ez **ji** te hez dikim.* = Seni seviyorum.
Ergatiflik birleşik fiillerde de geçerlidir (çünkü *kirin* geçişlidir): *Min ji te hez kir.* = Seni sevdim.

Yabancı kökenli birçok fiil de bu yolla Kurmancî'ye girer: *telefon kirin*, *qebûl kirin* (kabul etmek, Arapça kökenli).

## 5.4 Edilgen çatı (lêkera nediyar)
Yapı: **hatin** (gelmek) + **mastar**. Türkçedeki "-ıl/-ın" ekinin karşılığıdır.

| Etken | Edilgen |
|---|---|
| *Min nan xwar.* (Ekmeği yedim.) | *Nan **hat xwarin**.* (Ekmek yendi.) |
| *Ew nameyê dinivîse.* (Mektubu yazıyor.) | *Name **tê nivîsîn**.* (Mektup yazılıyor.) |
| | *Name **dê bê nivîsîn**.* (Mektup yazılacak.) |

Edilgen cümlede *hatin* geçişsiz olduğu için ergatiflik yoktur: *Ez hatim dîtin.* = Görüldüm.

**Ağız notu:** Bazı ağızlarda edilgen çatı *-(i)rîn* ekiyle de yapılır: *kirin* → *kirrîn* (yapılmak).

## 5.5 Ettirgen çatı
Yapı: şimdiki gövde + **-andin** (geçmiş) / **-în-** (şimdiki). Türkçedeki "-dır, -t" ekinin karşılığıdır.

| Temel fiil | Ettirgen | Şimdiki zaman |
|---|---|---|
| *kenîn* (gülmek) | *kenandin* (güldürmek) | *dikenînim* |
| *şewitîn* (yanmak) | *şewitandin* (yakmak) | *dişewitînim* |
| *gerîn* (gezmek) | *gerandin* (gezdirmek) | *digerînim* |
| *tirsîn* (korkmak) | *tirsandin* (korkutmak) | *ditirsînim* |

Bazı ettirgenler ayrı kökten gelir: *ketin* (düşmek) → *xistin* (düşürmek); *mirin* (ölmek) → *kuştin* (öldürmek).

## 5.6 Birleşik isim ve sıfat
- **İsim + isim:** *serok* (başkan) < *ser* (baş) + *-ok*; *rojname* (gazete) < *roj* (gün) + *name* (mektup).
- **Sıfat + isim (bahuvrihi):** *dilxweş* (mutlu, "kalbi hoş"), *serbilind* (onurlu, "başı yüksek").
- **İsim + şimdiki gövde:** *nivîskar* (yazar), *xwendekar* (öğrenci) < *xwend-* + *-ekar*; *ziman-zan* (dilbilimci, "dil bilen").
