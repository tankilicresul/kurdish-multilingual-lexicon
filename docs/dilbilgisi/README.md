# Kurmancî Başvuru Dil Bilgisi · Rêzimana Kurmancî

> ⚠️ **Taslak, uzman incelemesi bekliyor.** Bu bölüm betimleyici bir başvuru dil bilgisidir. Standart yazılı Kurmancî'yi (Hawar alfabesi, Bedirxan geleneği) anlatır. Kurallar yerleşik başvuru eserlerinden derlenmiştir ([0.2](00-giris-ve-yontem.md#02-temel-kaynaklar)). Örnekler Leipzig glossing kurallarıyla verilir. Kurmancî örneklerin yazımı Rastnivîs denetiminden geçirildi. Hiçbir bölüm henüz bir dilbilimci ya da anadil konuşucusu tarafından incelenmedi.

Anlatım dili Türkçedir. Gerektiğinde Türkçeyle tipolojik karşılaştırma yapılır. Terimlerin Kurmancî ve İngilizce karşılıkları için: [terimler.md](terimler.md).
